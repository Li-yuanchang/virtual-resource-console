VRC 0.1.71 新增堡垒机访问绑定与 ARP 二层占用预检。

- 新建 VM 可绑定堡垒机访问：安装时写入 sshd 白名单，仅放行配置来源，装完验证通过后锁定 sshd 配置；创建弹框默认勾选，设置页可配置来源。
- 新增二层 ARP 占用预检：候选 IP 只要有 ARP 应答即禁止创建，避免只测 ping 漏判导致的 IP 冲突；原探测文案明确为 ICMP。
- 安装验收超时提示区分 SSH / WinRM，并识别收尾前被删除或改名的 VM。
- 关机/强制断电结果明确标注“已强制断电”；VMware 正常关机等待延长到 120 秒，减少误判超时。
- 读取启动内核失败不再阻断重启，自动按系统默认内核重启并给出提示。
- 创建窗口统一使用图形控制台（VNC）；服务重启自动收尾无法恢复的创建任务；审计日志去重降噪。
