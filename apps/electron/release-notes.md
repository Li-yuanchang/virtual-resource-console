VRC 0.1.65 优化启动内核选择与开机提醒。

- 关机不再弹出“选择下次启动内核”，仅重启时选择内核（机器运行中可真实设置一次性启动项）。
- 重启时静默读取内核列表，仅当识别到多个启动内核时才弹出选择框，单内核直接重启。
- 开机确认时若近期读取过该虚拟机内核列表且多于 1 个，附加“按系统默认内核启动”提醒；如需指定内核，请开机后使用“重启”选择。
- 内核数量仅在本地缓存 7 天，只存数量、不存系统凭据。

VRC 0.1.64 存储指标卡片细化与创建虚拟机默认自动启动。

- 资源总览存储卡片新增 HBA / LVM 分类高亮，“剩余 / 可分配”统一按可承载 VM 磁盘的存储池口径统计，ISO 镜像库、可移动介质等不再混入剩余容量。
- 存储池详情支持“按磁盘类型分列（HBA / LVM）”与“总体展示”两种模式，可在设置中切换；总体模式底部保留 HBA / LVM 分布色点。
- 创建虚拟机流程固定为创建后自动启动，不再允许调用方关闭自动启动。

VRC 0.1.62 快照查看入口迁移到物理机总览。

- “查看快照”从虚拟机操作列移到物理机总览按钮栏，按物理机维度查看该宿主机下全部虚拟机的快照。
- 快照按虚拟机分组展示（名称 / 创建时间 / ID），单台虚拟机快照读取失败不影响整台物理机的快照总览。
- 虚拟机操作列不再展示快照入口，界面更聚焦开机 / 关机 / 强制重启 / 扩容等常用操作。
