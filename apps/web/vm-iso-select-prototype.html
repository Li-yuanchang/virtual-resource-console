系统镜像选择器

三套下拉框方案对比 · 触发同一个弹层，可直接操作测试

点击输入框展开 · ↑↓ 移动 · Enter 选择 · Esc 关闭 · 输入文字过滤
方案 A · 推荐

摘要行 + 搜索 + 分组扁平列表

改动最小

每行两行文本：名称 + “来源 · 大小”，右侧对勾只标记当前选中项。搜索固定 30px，头部菜单 28px，选中态只用左侧 2px 竖条 + 浅底，避免现在那种整行变绿变蓝的色块。

安装类型CLICPU4内存 GiB8
  • 刷新按钮从“飘在头部右侧”改为搜索框内的文字级图标，鼠标悬停才显底色。
  • 分组之间用 序号 + 名称 + 数量 细分隔线，替代现在厚重的分组标题条。
  • 每行高度 42px，列表最大高度 300px，超出内部滚动，不影响弹窗高度。
方案 B

镜像卡片列表（L0 徽标 + 元信息）

信息最全

每行左侧是系统族徽标（CentOS/Ubuntu/Windows/麒麟…），主体两行：ISO 文件名 + 存储库路径；右侧大小与对勾。适合镜像多、需要一眼区分系统的场景，但行高 52px，同样面积可见条数更少。

安装类型CLICPU4内存 GiB8
  • 徽标用主题色 8% 淡底 + 同色文字，不引入新色板。
  • 第二行把“共享/本地”做成 4px 小圆点 + 文字，比整块标签更轻。
  • 文件后半段用省略号截断，完整路径放 title。
方案 C

极简单行 + 右侧来源列

密度最高

单行 32px，三列栅格：文件名 / 来源 / 大小，斑马纹 + 悬停底色。最快扫读、最省高度，代价是失去“分组”语义，来源信息挤在同一行右侧。

安装类型CLICPU4内存 GiB8
  • 表头行固定显示“镜像 / 来源 / 大小”，列表是严格对齐的表格感。
  • 选中态换成行首 2px 主题色竖条，不再整行染色。
  • 需要分组时可在“来源”列做排序置顶，而不是插入分组标题。
确认方案后，按对应 DOM 结构改造 VmProvisioningDialog 的镜像选择器头部/选项模板，并同步 styles.css 中 .vrc-provision-iso-dropdown 样式。
