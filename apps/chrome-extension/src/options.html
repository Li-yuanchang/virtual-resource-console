设置 / Chrome 插件

该配置只作用于 Chrome 插件，不影响 Web、macOS、Windows 客户端。

Chrome 插件配置项 配置后端地址、本地连接库、临时会话和插件弹窗行为。
VRC API 服务插件只保存入口地址，资源能力仍由后台执行。
部署边界 nginx 只做 HTTPS、反向代理和访问控制；XenAPI、控制台 WebSocket、临时连接仍必须由 VRC API 处理。 
POST /api/ephemeral-connections
GET  /api/inventory/*
WS   /api/console/*

connectionStore: disabled
sessionStore: memory ttl=30m
本地连接库连接信息只在当前浏览器本地保存，保存前用主密码加密。
名称平台Host存储状态操作
新增连接明文密码只用于本次加密，不写入服务器。

使用 chrome.storage.local；禁止 chrome.storage.sync；密文可导出，明文不能写文件。

临时连接会话后台只保存在内存，过期立即失效。
执行链路插件解密后只交给后台短期使用。
1插件解锁本地连接库用户输入主密码，WebCrypto 解密连接。 2创建 ephemeral connectionAPI 只生成内存 ID，不写 connectionStore。 3业务接口使用临时 ID资源、控制台、任务都走 connectionId。 4TTL 到期自动清除日志不得记录密码，只记录摘要和 ID。
插件弹窗预览保持轻入口，只处理地址、健康检测和打开控制台。
