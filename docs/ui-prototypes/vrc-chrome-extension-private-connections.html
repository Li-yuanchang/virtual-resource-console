VRC API 凭据 不落盘 ephemeral connection TTL 30 分钟
用户系统 暂不需要 除非后台保存多人连接信息
Chrome 插件配置项 设置入口统一，但配置口径和 Web / macOS / Windows 分开
VRC API 服务 插件只保存入口地址，资源能力仍由后台执行
为什么不能只部署 nginx nginx 不是 VRC 后端
边界： nginx 只能做 HTTPS、反向代理和访问控制；XenAPI、控制台 WebSocket、临时连接会话仍必须由 VRC API 处理。
